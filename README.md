# Data Analysis Projects

Портфолио учебных и практических проектов по анализу данных.

Здесь я собираю проекты, которые помогают мне развивать навыки, необходимые для работы Data Analyst: работа с данными, SQL, Python, статистика, визуализация и формулирование выводов на основе данных.

## Стек

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Statsmodels
- SQL / PostgreSQL


## Что изучаю сейчас

В процессе развития портфолио я добавляю проекты по:

- SQL и продуктовой аналитике
- A/B-тестированию и статистике
- когортному анализу и retention
- EDA и визуализации
- построению аналитических выводов и рекомендаций

## Цель

Сформировать портфолио, демонстрирующее не только знание инструментов, но и умение решать реальные аналитические задачи: от подготовки данных и расчёта метрик до интерпретации результатов и формулирования рекомендаций.
