# A/B Test Analysis: Marketing Campaign Performance

Анатизируем результаты A/B-тестирования двух рекламных кампаний (Control vs Test). Цель проекта — оценить эффективность маркетинговых воронок, конверсии на каждом этапе, а также экономическую целесообразность раскатки тестового варианта.

## 📌 Основные стеки и инструменты
* **Python**: `pandas`, `numpy` — предобработка данных и агрегаты
* **Статистика**: `statsmodels`, `scipy.stats` — Z-тест пропорций, проверка статистической значимости ($p$-value, доверительные интервалы)
* **Визуализация**: `matplotlib`, `seaborn`

## 📊 Результаты исследования

| Этап воронки / Метрика | Control (%) | Test (%) | $p$-value | Стат. значимость | Победа |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **CTR** (Impressions → Clicks) | 4.86% | **8.09%** | < 0.0001 | Да | **Test** |
| **Click → View Content** | **80.99%** | 51.52% | < 0.0001 | Да | **Control** |
| **View → Add to Cart** | **38.08%** | 30.67% | < 0.0001 | Да | **Control** |
| **Add to Cart → Purchase** | 40.21% | **59.13%** | < 0.0001 | Да | **Test** |
| **Overall Conv** (Clicks → Purchases) | 12.41% | **9.33%** | < 0.0001 | Да | **Control** |
| **CPA** (Cost Per Action) | **$4.41** | $4.92 | < 0.0001 | Да | **Control** |

## 💡 Ключевые выводы

1. **Привлечение и "дожим" (Test):** Тестовая кампания показывает значительно более высокий **CTR ($8.09\%$ vs $4.86\%$)** и отлично конвертирует пользователей из корзины в покупку (**$59.13\%$ vs $40.21\%$**).
2. **Воронка вовлечения (Control):** Контрольная кампания лучше удерживает пользователя в середине воронки (переход от клика к просмотру контента и добавление в корзину).
3. **Экономика (CPA):** Несмотря на высокий CTR и хорошую конверсию корзины в Test, итоговая стоимость привлечения покупки (CPA) в тестовой группе оказалась на **11.5% выше** ($4.92 против $4.41 в Control).

## 🚀 Бизнес-рекомендация

* **Не рекомендуется** масштабировать вариацию **Test** в текущем виде, если приоритетом компании является юнит-экономика и минимальный CPA.
* **Гибридный подход:** Рекомендуется заимствовать креативы/заголовки из Test для первичного привлечения (высокий CTR), но доработать интерфейс карточек товаров (просмотр → корзина) по образцу Control-версии.
