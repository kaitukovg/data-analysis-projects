# Network Traffic Monitoring with PostgreSQL & TimescaleDB

Проект по мониторингу сетевого трафика с автоматическим обнаружением аномальных всплесков.

В основе проекта PostgreSQL + TimescaleDB. Данные агрегируются по времени с помощью `time_bucket()`, а для расчёта динамического порога используются SQL оконные функции `AVG() OVER` и `STDDEV_SAMP() OVER`.

## Что делает проект

Проект имитирует поток сетевого трафика и анализирует его во времени:

1. Генерирует тестовые данные сетевого трафика.
2. Загружает данные в PostgreSQL / TimescaleDB.
3. Хранит данные в hypertable.
4. Создаёт continuous aggregate для почасовой агрегации.
5. Рассчитывает минутный трафик.
6. Вычисляет скользящее среднее за 15 минут.
7. Рассчитывает скользящее стандартное отклонение.
8. Формирует динамический порог:

`threshold = rolling_mean + 1.5 × rolling_std`

9. Определяет значения, превышающие динамический порог.
10. Находит час с максимальным объёмом трафика.
11. Строит график с визуальным отображением аномалий.
